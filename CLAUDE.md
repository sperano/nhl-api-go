## Architecture

This is a Go client library for the NHL Stats API. All code lives in the `nhl` package.

### Core Components

**Client (`client.go`)**: The main API client that wraps HTTP requests to NHL endpoints. Uses `NewClientWithBaseURL()` for testing with mock servers.

**Endpoints**: The client communicates with four NHL API endpoints:
- `api-web.nhle.com/v1/` - Primary web API (standings, schedules, boxscores, players)
- `api.nhle.com/` - Core API
- `api.nhle.com/stats/rest/` - Stats API (shift charts, franchises)
- `search.d3.nhle.com/api/v1/` - Search API (player search)

### Type System

**Strongly-typed enums**: `GameType`, `GameState`, `Position`, `Handedness`, `PeriodType`, `HomeRoad`, `ZoneCode`, `PlayEventType`, `GameScheduleState`, `DefendingSide`, `GoalieDecision` - all implement custom JSON marshaling/unmarshaling and validation. The string-backed enums are generated by `internal/enumgen` into `enums_generated.go` (defined in `internal/enumgen/defs.go`); hand-written domain methods live in `enums.go`. `GameType` is int-backed and hand-written in `game_type.go`. On an unrecognized value, `FromString`/`UnmarshalJSON` return a typed `*UnknownEnumValueError` (recoverable via `errors.As`).

**ID wrapper types** (prevent mixing up different identifier types). `GameID`, `PlayerID`, and `TeamID` are generated by `internal/idgen` into `ids_generated.go`:
- `GameID`: 10-digit game identifiers encoding season, game type, and game number. Use `GameID(2024020001)`. Domain methods (`Season()`, `GameType()`, `Validate()`, …) are in `game_id.go`.
- `PlayerID`: Player identifiers. Unmarshals from int or string JSON. Use `PlayerID(8478402)`.
- `TeamID`: Team identifiers. Use `TeamID(10)`.
- `Season` (`date.go`): Season values like 20232024. Use `NewSeason(2023)` for the 2023-2024 season, or `FromYears(start, end)` to record an explicit end year. Unmarshals from int, int64, or string JSON. `String()` returns `"2023-2024"` format.

**Date handling**: `GameDate` handles NHL-specific date format (YYYY-MM-DD).

**LocalizedString**: Handles NHL API's `{"default": "value"}` format for internationalized strings.

### API Response Types

Response types match NHL API structure:
- `Standing`, `StandingsResponse` - Team standings
- `ScheduleGame`, `DailySchedule`, `WeeklyScheduleResponse` - Game schedules
- `Boxscore`, `PlayByPlay`, `GameMatchup` - Game data
- `PlayerLanding`, `PlayerGameLog`, `PlayerSearchResult` - Player data
- `ClubStats`, `ClubSkaterStats`, `ClubGoalieStats` - Team statistics
- `Roster`, `RosterPlayer` - Team rosters

### Error Handling

Error types are in `errors.go` (plus `UnknownEnumValueError` in `enums.go`):
- `APIError` - carries an HTTP `StatusCode` and message; returned for non-2xx responses. On a non-2xx, `getJSON` appends a bounded slice of the response body to the message.
- Sentinel `*APIError` values for `errors.Is` matching: `ErrBadRequest` (400), `ErrUnauthorized` (401), `ErrNotFound` (404), `ErrRateLimited` (429), `ErrServerError` (500, and matches any 5xx).
- `RequestError`, `JSONError` - wrap underlying request/decode errors (support `errors.Unwrap`).
- `UnknownEnumValueError` - returned when an enum value from the API is unrecognized; carries `EnumType` and `Value` and survives `JSONError` wrapping.

### Testing Pattern

Tests use `httptest.NewServer` with `NewClientWithBaseURL()` for mocking. Helper functions `makeJSONResponse()` and `makeErrorResponse()` simplify test setup.
